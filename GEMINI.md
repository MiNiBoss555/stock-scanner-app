# Stock Scanner Project Rules

These rules apply to the entire project, with a focus on the Flutter mobile application.

## Flutter Development
- **State Management**: Use `provider`.
- **API Logic**: All API calls and backend communication must reside in `lib/api_service.dart`.
- **Null Safety**: All Dart code must use null safety.
- **Generated Files**: Do not modify files generated by Flutter or other tools (e.g., `*.g.dart`).
- **Coding Style**: Follow the existing coding style and patterns found in `lib/`.

## Architecture
- Backend: FastAPI (Python)
- Database: SQLite
- Frontend: Flutter
